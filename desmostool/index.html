The Desmos Trace Tool


Trace Tool


Usage



1. Go to the 3D calculator.
2. Enter a 3D equation in the first box.



3. Click the Trace Tool in your bookmarks bar


To disable the Trace Tool, simply click the X on Traces


To reset the trace sliders, click the button next to Reset Sliders

Features

Inline Usage - runs in Desmos


Trace Dynamic Update - No rerun needed



Hyperbolic Paraboloid Detection
